## 🌐 Simple Animated Portfolio

A responsive and visually engaging **personal portfolio website** built with **HTML, CSS**, and **JavaScript**. This project showcases smooth animations, a clean layout, and interactive elements to highlight your skills, projects, and contact information.


---

### 🚀 Features

* ✨ Smooth scroll animations
* 📱 Fully responsive design (mobile, tablet, desktop)
* 💡 Interactive navigation menu
* 🧩 Modular code structure
* 🖼️ Image and content fade-in animations
* 🌙 Optional dark mode toggle (if implemented)

---

### 📁 Project Structure

```bash
simple-animated-portfolio/
│
├── index.html             # Main HTML file
├── css/
│   └── style.css          # Stylesheet with animations and layout
├── js/
│   └── script.js          # JavaScript for interactivity

```
